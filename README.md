# Maison Rivière

A polished, dependency-free static portfolio website concept for a fictional luxury Detroit wedding venue.

## Deploy
Upload the contents of this folder to a GitHub repository and deploy as a static site on Vercel, Netlify, GitHub Pages, or any standard web server. No build command is required.

### Vercel
Framework preset: **Other**  
Build command: **none**  
Output directory: **./**

## Pages
- Home
- Weddings
- The Estate
- Experience
- Gallery
- Investment
- Wedding Builder
- Schedule a Tour

## Notes
Maison Rivière is a fictional portfolio concept. All venue claims, pricing, testimonials, and guest counts are illustrative.
